# Privacy Policy

**Last updated: September 20, 2026**

This Privacy Policy explains how the app handles information.

## No Personal Data Collection

This app does not collect, transmit, sell, or share personal data with the app developer or any third-party server.

The app does not use advertising, analytics, tracking technologies, or user profiling.

## Session Data

The app is designed to analyze foil pumping sessions.

During a session, the companion watch app analyzes the session in real time and records the session trace. When the session is finished, the trace is transferred from the watch to the phone app.

The phone app stores and displays the session analysis and allows the user to share the session trace.

Session data is processed and stored locally on the user's devices. The developer does not receive or have access to this data.

## Sharing

The phone app may allow the user to share a session trace using the sharing functionality provided by the operating system.

Sharing is initiated by the user. Once a trace is shared with another application or service, its handling is governed by that application or service's own privacy policy.

## Network Communication

The app does not send session data or personal information to developer-operated servers.

If the operating system or another application involved in sharing communicates over the internet, that communication is controlled by the operating system or the third-party application.

## Open Source

The source code of this application is publicly available as open source. Users can inspect the source code to understand how the application handles data.

## Children's Privacy

Because the app does not collect personal information, it does not knowingly collect personal information from children or other users.

## Changes to This Privacy Policy

This Privacy Policy may be updated if the app's data practices change. The updated version will be published at the same location.
