## 📦 Install the App

Download the latest APKs from the **[GitHub Releases](../../releases)** page.

### 📱 Phone

1. Download **`FoilTrackerPhone-debug.apk`**.
2. Open the APK on your Android phone.
3. Allow installation from unknown sources if prompted.
4. Install and launch **FoilTracker**.

### ⌚ Wear OS Watch

Install the watch APK using **Wear Installer 2** on your Android phone.

1. Download **`FoilTrackerWatch-debug.apk`** from the [GitHub Releases](../../releases) page.
2. Install **Wear Installer 2** on your Android phone.
3. On your watch, enable **Developer options**, **ADB debugging**, and **Wireless debugging**.
4. Open Wear Installer 2 and follow its **Pair with watch** instructions.
5. Select **Custom APK**, choose `FoilTrackerWatch-debug.apk`, and tap **Install**.

> Your phone and watch should be on the same Wi-Fi network. Disable debugging after installation.

> **For the full phone + watch experience, install both APKs.**
